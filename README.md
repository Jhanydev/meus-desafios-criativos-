## 🧠 Desafio 1 — Planejando Automações com N8N Usando Apenas Bons Prompts

### 📌 Objetivo
Construir um prompt claro, contextualizado e estruturado capaz de orientar uma IA a planejar uma automação no **N8N**, seguindo o modelo de três etapas:

1. **Definir a automação** (processo, público e resultado esperado)
2. **Adicionar contexto e regras** (ferramentas, fluxo e restrições)
3. **Montar o prompt final** (unindo todas as peças)

### 🛠️ Automação Planejada
Uma automação para **registrar e qualificar leads recebidos por formulário**, integrando:

- **Google Forms** — captura das respostas
- **Google Sheets** — armazenamento dos dados
- **Gmail** — envio de e-mail de confirmação ao lead
- **Slack** — notificação do time comercial para leads de alto interesse

### 🔗 Acesse o Prompt Final
👉 [`desafio-n8n.md`](./desafio-n8n.md)

### ✨ Destaques do Prompt
- Validação de e-mail antes do envio
- Controle de duplicidade (24h)
- Classificação por nível de interesse
- Auditoria de registros inválidos em aba separada
- Notificação no Slack em até 1 minuto para leads "alto interesse"
